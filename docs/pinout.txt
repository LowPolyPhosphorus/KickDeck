KickDeck Pinout

OLED (SSD1306, I2C4)
VCC -> Pin 1 (5V)
GND -> Pin 16
SDA -> Pin 9
SCL -> Pin 13

Rotary Encoder (EC11)
CLK -> Pin 14 (GPIO_PC7)
DT  -> Pin 3  (GPIO_PH5)
SW  -> Pin 5  (GPIO_PH4)
VCC -> Pin 2  (3V3)
GND -> Pin 6

Power Button (RGB ring, only Green wired)
Switch -> wired in parallel with UPS HAT (E) onboard ON/OFF slide switch leads
C+ / C- -> 5V rail (LED common)
G   -> 5V rail (direct, always on)
R   -> not wired
B   -> not wired

Indicator LEDs
HDD Activity (dim, PWM) -> Pin 10 (PWM1)
  GND -> Pin 19
Battery Level / Low Battery -> Pin 12 (GPIO_PC12)
  GND -> Pin 19

Fan
+ -> 5V Rail
- -> GND

USB Port 1 -> Internal hub
  Hub Port 1 -> Touch controller (data)
  Hub Port 2 -> Keyboard/touchpad combo
  Hub Port 3 -> 32GB Flash drive
  Hub Port 4 -> Display Power

USB Port 2 -> External hub
  Hub Port 1 -> spare (external)
  Hub Port 2 -> spare (external)
  Hub Port 3 -> spare (external)
  Hub Port 4 -> spare (external)

UPS HAT (E)
USB-C in  -> charging input only (wall charger)
USB-A out -> K2B power (USB-C in on K2B)
Onboard ON/OFF slide switch -> tapped in parallel by Power Button switch contacts
